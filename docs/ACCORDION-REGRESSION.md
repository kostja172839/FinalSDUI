# Стабильный отступ аккордиона

В SDDS FinAI 0.369.0 содержимое аккордиона по умолчанию выравнивается с заголовком. Компонент измеряет ширину левой иконки через `offsetWidth`. Если он впервые смонтирован в скрытой вкладке, ширина равна нулю. При повторном раскрытии измерение повторяется, поэтому отступ меняется с 0 на 22 px.

Адаптер Split-view использует фиксированный вид левой иконки — chevron. Через публичный `bodyProps.style` отступ определяется как сумма токенов размера иконки и промежутка. Отображение больше не зависит от измерения скрытого DOM и остаётся согласованным с размерами kit.

Регрессионная проверка реального браузерного сценария: [tests/browser/accordion-indent.cua.js](../tests/browser/accordion-indent.cua.js). Она перезагружает приложение, впервые открывает вкладку «Стоимость, количество», измеряет положение содержимого, закрывает и открывает «Бухгалтерский учёт» и сравнивает значения.

- До исправления: первоначальный отступ 0 px; после раскрытия 22 px; проверка падает.
- После исправления: первоначальный отступ 22 px; после раскрытия 22 px; проверка проходит.

Это проверка с CUA Tab в реальном браузере, а не часть DOM-less команды `pnpm test`. Обычный Node-тест не воспроизводит измерение ширины иконки в скрытой вкладке.
